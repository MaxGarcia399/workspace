04 / REAL FEATURES
What is within reach.
Included features. Extra requirements are shown where needed.
01
Create or load agents
included
Add agentfrom the hub
↳
The installation starts without agents. Create your first one from a template or load an existing brain.
See the flow
Name + identity → brain folder → machine registry → agent available in the hub. Basic scaffolding is local; AI personalization is optional.
02
Local calendar
included
eventdate · time · notes
↳
Save. The event stays in this machine’s agenda, with date, time and notes.
See storage and limits
The agenda lives in personal.json, per machine. Trash keeps deleted events for 15 days; they expire afterwards. This does not promise cross-device syncing.
workspace calendario
03
GitHub in the terminal
requires gh
your reposlocal checkouts
↳
Review local branches and inspect PRs, issues and releases from the hub. Remote information refreshes when requested.
What you need
For the GitHub layer, install GitHub CLI and run gh auth login. Without that login, the remote layer is disabled; the local view remains available.
gh auth login
04
Customization
included
your settingsper machine
↳
Change theme and background separately. Adjust tone dials and the hub’s shortcuts.
What changes
These are local settings on your machine. Tone dials add instructions to the agent; how they are followed depends on the model. A terminal theme does not change the brain’s written identity.

[ manual alternative · macOS ]
$git clone https://github.com/MaxGarcia399/workspace.git ~/Desktop/Workspace
python3 ~/Desktop/Workspace/install.py
  • Python 3.9+ and Git installed.
  • Claude Code, Codex or Antigravity: CLI installed and authenticated separately.
  • GitHub CLI is optional, for remote GitHub features.
The harness uses Python’s standard library. AI engines and accounts are installed separately; their terms and costs are set by the provider.
