# _propuestas — cuarentena del skill loop automático

Las skills NUEVAS que proponga el review automático de WORKSPACE (`hooks/skill_review.py`,
SessionEnd) aterrizan aquí con `status: propuesta` — **nunca directo al catálogo**.

- **Aprobar** (solo un socio): mover la carpeta a su categoría, quitar `status: propuesta`,
  registrar en `skills/README.md` (+ INDEX-LITE si cambia el conteo/categorías).
- **Descartar:** borrar la carpeta (es lo único que sí se borra — nunca entró al catálogo).
- `_mejoras/`: propuestas de mejora/reescritura que genere el audit pipeline (N4) para skills
  existentes — mismo gate humano.
