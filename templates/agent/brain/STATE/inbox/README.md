# inbox/ — notas append-only para {{AGENT_DISPLAY}}

Socios u otros agentes me dejan aquí encargos, contexto o handoffs: `<socio>-YYYY-MM-DD.md`
(o `<agente>-YYYY-MM-DD.md`). Los proceso al arrancar sesión: aplico/agendo lo que corresponda,
registro en `log-recent.md` y muevo lo procesado a `consumed/`.

Es el patrón append-only del equipo (ver `wiki/concepts/append-only-state.md` en el cerebro
principal del equipo): nadie escribe mis canónicos directo — me dejan la nota y yo la aplico.
