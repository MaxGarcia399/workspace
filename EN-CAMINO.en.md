# v0.9.1
stage: development
author: Workspace team
updated: 2026-11-10

We're finishing v0.9.1. It's a release that keeps everything your agents decide clear and under your control: you'll also see the questions that ended up without a decision, and no change to a skill is applied without being reviewed first.

## What's coming
- **Decisions without an outcome** — Deciders also shows the questions that ended up without a decision.
  Today you only see the questions that ended in a decision. With v0.9.1 you'll also see the ones that didn't, so none of them gets lost.
- **Skills review** — Changes to a skill are reviewed before they're applied.
  When an agent suggests improving a skill, the change goes through a review first. Your skills get better without anything changing blindly.
- **Official site** — Docs in Spanish and English and live updates, all in one place.
  The install guide, the full documentation and this updates channel, refreshed live from GitHub.
